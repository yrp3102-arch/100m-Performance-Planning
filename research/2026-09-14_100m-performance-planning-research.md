    # 100m Performance Planning 研究报告

## 研究范围与核心判断

本报告研究如何设计、评价和动态调整以竞技性100米表现提升为主要目标的训练计划。主要适用人群为已有一定系统短跑与力量训练经历的成年或接近成年运动员。青少年、初学者、团队运动员、耐力运动员和世界级短跑选手的证据均需经过人群与任务匹配后才能外推；训练年龄不能用生理年龄或“运动员”这一标签代替。

本报告的交付对象是未来训练设计工具的知识基础，内容是问题、变量、证据、条件和决策结构，不包含具体周计划，也不直接构建 Skill。

核心判断是：训练计划的适当性主要取决于其与运动员、目标、时间和约束的匹配，但计划本身仍有可独立检查的质量属性，例如信息完整、剂量明确、内部一致、可以执行与追踪。比较方案时应先排除不满足必要条件的方案，再比较其预期专项收益、恢复与组织成本、风险和对不确定性的承受能力。不能只看动作清单、计划完成率或某次比赛的结果。

更有解释力的计划模型是“时间约束下的可更新策略”：预先安排提供方向与协调，反馈决定局部调整，阶段目标与比赛日期限制调整的范围。这是本报告提出的综合模型，尚不是经过竞技100米长期对照试验验证的成套系统。

## 证据使用与检索边界

检索截至2026年9月14日，覆盖期刊与PubMed公开记录、可访问全文、出版社原书节选、教练本人或执教机构公开材料，并沿关键综述追踪原始研究及相反观点。检索主题包括100米表现、生物力学、刺激与剂量、残留效应、周期组织、恢复、监测、自动调节、阶段转换和减量。近期检索纳入了2025年的阻力短跑综述及2026年的力量速度损失研究，避免把2019年的实践综述当成最新全貌。

这是一份结构化证据综合与决策框架报告，**不是完成注册、双人独立筛选、穷尽数据库检索和逐研究正式偏倚评价的PRISMA系统综述**。没有自行合并效应量，没有把搜索命中数当作纳入研究数。仅能访问摘要的文献，只用于摘要能够支持的结论；没有取得原著全文时，不给出虚构页码或逐字引文。相关局限在Part XI和参考文献中记录。

采用两套互不替代的标签：第一套是来源类型A—F；第二套是对具体决策主张的确信程度。系统综述可归A，但如果其研究主要来自青少年足球或终点为CMJ，它对受训练100米运动员的计划选择可能只有间接意义。叙述性综述不因发表在同行评议期刊就自动进入A；其机制、实践和观点部分分别标注。

## Part I — Training Plan Ontology

### 1. 概念、区别与重叠

这些术语没有跨所有训练学文献的唯一标准定义。以下是用于后续设计的工作定义，不应宣称为统一国际术语。出版社对periodization、planning、programming的区分也强调：周期化可包含监测和可修改的参数，而非只能是固定日历。[^1]

| 概念 | 工作定义 | 典型输出与边界 |
|---|---|---|
| Training plan | 在目标、运动员状态和约束下，安排训练、评价反馈并规定如何更新的意图与行动方案 | 包括时间结构、具体处方及修正规则；不要求未来所有细节都已确定 |
| Training program | 一段时期组织起来的训练内容与实施安排 | 可能只是课表，也可能与plan同义；需看实际内容而非词名 |
| Periodization | 围绕时间和比赛组织重点、负荷与表现表达的框架 | 是计划的时间组织层，不是全部训练设计 |
| Programming | 将目标转成刺激、动作、剂量、顺序和进退阶的具体设计过程 | 可发生于全年、阶段或单课层面，不局限于配组数 |
| Training prescription | 一次或一类训练的可执行处方 | 明确动作、速度／负荷、量、间歇、质量要求、替代方案和终止条件 |
| Training monitoring | 持续记录外部剂量、内部反应与表现，支持解释和决策 | 收集数据不是自动调节；监测需要对应的决策用途 |
| Autoregulation | 按事先可说明的规则，依据当下或近期反应修改处方 | 不等于随机训练、随心练或每次追求最佳成绩 |

### 2. 计划的最低信息结构

“最低”应理解为最低信息充分性，而非每次输出必须填满几十栏。已有档案可被引用，但不能默默假定其仍然有效。

| 信息组 | 最低内容 | 缺失造成的问题 |
|---|---|---|
| 目标 | 主要比赛／测试结果、阶段目标、优先级、时间窗口 | 无法判断何种适应值得成本 |
| 运动员与现状 | 训练年龄、竞技水平、近期专项表现、既往反应、组织状态 | 同一剂量可能过轻、合适或过重 |
| 刺激与剂量 | 适应目标、方法、量、强度参照、实际速度、间歇与频率 | 无法复现，动作名称被误当成刺激 |
| 时间与顺序 | 课内顺序、课间关系、比赛与旅行等硬约束 | 单课各自合理，组合后互相损害 |
| 恢复安排 | 预期恢复成本、可用睡眠与时间、低负荷活动预算 | “恢复日”变成隐藏的训练日 |
| 推进与回退 | 何时维持、增加、减量、换方法；每次改变哪一维 | 把完成训练或日历翻页误作适应 |
| 监测 | 测量协议、参照基线、噪声、记录人和复核时间 | 指标很多，却不能解释变化 |
| 停止与转换 | 单课停止、阶段退出、医学问题转交、缺数据处理 | 计划只能继续，没有纠错路径 |
| 竞赛表达 | 重点比赛、热身与轮次需求、减量目标、替代窗口 | 体能发展与比赛准备脱节 |
| 决策依据 | 假设、证据、人群适用性、预期反应与不确定性 | 无法解释为何修改，更无法学习 |

这组最低结构属于F级设计提案：其各组成部分有不同证据支持，但整套字段尚无已验证的100米质量评分效度。

### 3. 三种计划模型的公平比较

| 模型 | 优势 | 主要限制 | 适用条件 |
|---|---|---|---|
| A：预先规定的时间表 | 协调场地、教练和比赛，稳定执行，降低随意调整 | 难以覆盖伤病、天气、生活压力及个体反应 | 条件稳定、短期窗口、处方已被个体证明可耐受 |
| B：反馈更新的决策系统 | 允许依据状态变化调整，保留个体差异 | 噪声可能造成频繁改动；测量和解释成本高 | 监测可靠、反馈及时、调整有边界 |
| C：带反馈的分层时间计划 | 长期目标相对稳定，近端安排更具体；有备选情景与复核点 | 规则太复杂可能难执行，规则本身仍需验证 | 受训练运动员、明确赛历、可持续记录与教练判断 |

不能从“生物反应不确定”推导出“预先规划无用”。Kiely对可预测适应和传统应激解释提出质疑；Hornsby等则提醒不能把某些力量实验或简化图示当作完整周期理论。两者共同约束本报告：既不把日历看成生理时钟，也不把即时反馈当作能解决一切的工具。[^2][^3]

采用C模型还需一个反过度调节原则：除明确症状或明显错误外，只有当新信息足以改变行动排序时才改计划。一次噪声很大的CMJ下降可以触发复核，但不必触发整个中周期重写。

## Part II — 100m Performance Model

### 1. 先定义结果，再定义限制因素

比赛结果可写为：枪响至启动的反应时间，加上启动后各非重叠距离段的时间。固定分段之和是记账恒等式；“加速、最高速度、减速”是对速度曲线的功能分解，边界因运动员而异。不能把0—30米永久等同于加速，把30—60米永久等同于MaxV。

直接组成表现的是反应与起跑执行，以及全程速度—距离曲线。加速能力决定多快建立速度；最高速度限制中段能够达到的水平；速度耐力影响进入高速后维持速度与技术的能力。它们相互关联：最高速度提高后，原来的同一绝对速度可能变得相对轻松；但更高速度也可能提高组织需求，不能保证后程自动改善。

评估“后程差”必须同时看进入后程时的速度、绝对分段时间和相对减速。某人减速比例小，可能是因为他根本没有达到很高速度；另一个人减速比例大，仍可能以更快的绝对速度完成终点。100米速度耐力也不同于短间歇反复冲刺能力，后者通常服务于多次重复输出。相关研究确实显示重复冲刺可改善部分体能终点，但不能据此替代一次100米高速维持任务。[^4]

### 2. 分层因果结构

以下关系图是概念结构，不是已拟合的因果模型。箭头表示可能的作用路径，并不保证某变量干预后成绩改善。

**形态／训练历史／组织状态 → 可用力与肌腱功能 → 特定速度和接触时间下的协调与力作用 → 速度曲线 → 100米成绩。**

**技术学习、疲劳与能量供给**同时作用于中间多个环节；**风、赛道、鞋、计时、起跑程序与比赛情境**影响观测结果。分析时必须把能力改变与测试条件改变区分开。

| 变量 | 在表现模型中的位置 | 关系与训练含义 |
|---|---|---|
| Acceleration | 速度曲线的直接特征 | 与产生有效水平冲量、姿态转换和逐步缩短的用力窗口相联系 |
| Maximum velocity | 速度曲线的直接特征 | 不是单一力量输出；需要高速支撑、摆动与落地时序配合 |
| Speed endurance／fatigue resistance | 后程速度保持的直接特征及其支持过程 | 要区分代谢疲劳、输出能力下降、协调变化和前段执行影响 |
| Sprint mechanics | 力学描述与可学习的协调方式 | 技术变量是耦合的；一个局部“更漂亮”的姿态不必然更快 |
| Force production | 支持能力或跑动中的直接力学变量 | 测力台跑动作用力比慢速力量测试更接近任务，但仍须解释方向和时序 |
| Force–time characteristics | 支持能力向跑动结果转化的约束 | 总力、早期力、冲量和可用时间需要一起解释 |
| Power | 力与速度共同决定的输出量 | 杠铃功率、跳跃功率、模型估计水平功率不是同一个构念 |
| Strength | 可用力储备 | 与专项速度和技术共同决定转移；不能假设无限提高1RM持续有益 |
| Reactive strength／SSC | 快速伸缩转换的任务能力 | 受预激活、协调、肌肉和肌腱特性影响；并非独立万能素质 |
| Muscle–tendon function | 力传递、储能回弹及承受负荷的支持系统 | 肌腱性质可适应，但组织变化和表现变化没有简单一一映射 |
| Coordination／technical skill | 组织自由度和任务执行 | 技术是在特定速度、环境和能力下形成的解决方案 |
| Anthropometry | 相对稳定的约束 | 肢段比例、质量分布影响个体技术；不能从小样本相关推导理想身材 |
| Energy systems | 瞬时与全程供能支持 | 磷酸原、糖酵解和有氧并行贡献，非按秒数开关切换 |

Morin等的小样本研究将100米与加速中的力方向、机械功率等联系起来；Weyand等研究了最高速度下支撑力与摆动时间。这些研究的任务、样本和速度阶段不同，不能用其中任何一篇证明“水平力永远重要”或“摆腿训练无意义”。[^5][^6]

肌骨模型显示高速跑中不同腘绳肌的力、应变和功各有特点；这支持考虑组织特异性成本，但模型估计不是直接测得的损伤阈值。肌腱负荷研究支持机械刺激可改变组织性质，也不能推出越硬越好或一套等长动作等于短跑弹性。[^7][^8]

100米通常为无氧供能占优，但比例依测量方法而变。Duffield等在同一研究中用不同估算方法得出显著不同的有氧占比，因此不宜用一个固定百分比反推每周有氧训练量，更不能把100米称为“纯磷酸原运动”。[^9]

### 3. 常用指标能说明什么

| 指标 | 能说明 | 不能说明／主要混淆 |
|---|---|---|
| Squat 1RM | 特定深度、动作和程序下的最大动态力量 | 不能直接等价于高速跑力输出、技术或100米潜力；体重和熟练度会影响结果 |
| CMJ | 特定垂直跳任务的整体输出及变化 | 不单独识别腘绳肌高速耐受；相同跳高可由不同下蹲深度与发力时间产生 |
| RSI | 指定反弹任务的跳高／接触时间关系 | 不是全身“弹性值”；箱高、着地策略和算法影响结果；RSI-mod定义不同 |
| Fly time | 助跑后指定区间的平均高速表现 | 不自动等于瞬时MaxV；助跑不足、区间位置改变会污染判断 |
| 30m time | 指定起跑和计时协议下的短距离综合表现 | 无法单独定位起跑反应、中后段加速或最高速度，更不能独立代表后程 |
| Ground contact time | 给定速度下接触时间的描述 | 不能证明越短越好；人为缩短可能同时降低有效冲量 |
| Step length | 步距这一结果变量 | 不能直接推出应主动跨大步；速度、体型与制动共同影响 |
| Step frequency | 单位时间步数 | 不能独立优化；刻意提频可能损害步长或力作用 |
| Sprint F–V profile | 在测量与模型假设成立时概括加速表现 | F0、V0常为外推参数，不能直接当作肌肉最大力或飞跑最高速度 |

步长×步频在一致定义下描述平均速度，是恒等关系，不是“两个独立旋钮”。RSI与运动表现的相关证据也不能证明提高RSI必然导致100米改善。[^10]力量增长与短跑改善的汇总研究支持力量作为候选工具，但其中效应量间的相关不是每位运动员的确定转移率。[^11]

## Part III — Training Plan Evaluation Framework

### 1. 适当性是条件关系，但不是相对主义

本报告建议使用：

**Q = 计划的信息与逻辑质量 + 在已知条件下的预期适当性 + 实施后根据反应更新的能力。**

这不是可相加的测量量表，而是评价的三个层面。一个没有剂量、参照强度或恢复安排的方案，即使运动员偶然进步，仍可能有结构缺陷。一个认真制定的方案，也可能因伤病、风或随机波动没有得到好成绩；单次结果不能追溯性证明最初决策错误。

条件式评价得到训练监测、复杂应激观点和复赛风险框架的支持：相同训练对不同状态的人并不等价，成功也与目标和可接受风险相关。[^2][^12][^13]反例是某些内容无论对谁都缺乏可执行性，例如单位矛盾、同一时段重复占用场地、宣称低负荷却没有任何总量边界。

### 2. 逐条件评价矩阵

| 条件 | 应掌握的信息 | 适当性判断 | 常见不适当表现 |
|---|---|---|---|
| Athlete | 年龄、成熟度、竞技水平、技术、个体偏好 | 处方能否被正确执行 | 只根据年龄或100米PB分类 |
| Goal | 100米、阶段目标和优先赛事 | 主要投入是否服务于当前最有价值的问题 | 为提高深蹲而持续牺牲高速跑 |
| Current state | 近期可重复表现、疲劳、症状 | 是能力不足、表达受限还是数据问题 | 所有表现下降都判为训练不够 |
| Training history | 有效、无效和不耐受剂量；中断史 | 是否利用个体已知反应 | 套用他人成功负荷 |
| Competition calendar | 重要性、轮次、密度、旅行 | 比赛是否计入高速暴露和恢复预算 | 比赛叠加在完整训练周之上 |
| Time horizon | 距目标剩余时间与长期发展 | 新适应来得及转移、恢复和熟练吗 | 临赛引入高学习成本动作 |
| Recovery capacity | 睡眠、营养条件、压力、可用时间 | 计划的恢复假设是否真实 | 默认全职精英的恢复资源 |
| Injury／tissue status | 局部症状、医生／康复限制、暴露史 | 下一剂量是否在已证明耐受范围附近 | CMJ正常便忽视跑动疼痛 |
| Facilities | 跑道长度、天气、鞋、器械、测量工具 | 能否达到目标速度并安全减速 | 短场地名义安排MaxV却始终达不到 |
| Lifestyle | 工作学习、通勤、训练时段 | 处方在现实中能否持续 | 用大量辅助训练挤占睡眠 |
| Uncertainty | 缺失变量、测量误差、证据间接性 | 是否需要更小试探剂量和复核 | 对未知状态使用精确大剂量 |
| Observed response | 即时、延迟和纵向反应 | 维持、推进、减少或改方法有无依据 | 只核对完成率，不更新假设 |

### 3. 比较better／worse的方法

先检查必要条件：能执行、有清楚目标、没有与已知组织限制直接冲突、剂量可解释。缺失关键资料时标记“不能判定”，而非给出一个看似客观的分数。

再比较可行方案的预期专项收益、占用的训练时间、局部和整体恢复成本、主要比赛前的表现可用性，以及失败后是否容易回退。可以用Pareto比较：如果A在核心收益不差、成本不高的同时至少一项更好，则偏向A；若收益与成本交换，则由阶段目标和运动员偏好决定，不能假定存在唯一赢家。

最后在实施后分别审计：处方是否实施、有效刺激是否实际达到、恢复成本是否超过预期、专项变化是否超出噪声、是否有更简单解释。建议保留“当时依据”，防止只用事后成绩评价计划质量。这是F级决策结构，不是已经校准的表现预测模型。

例如，同样增加深蹲，在近期力量明显不足且高速训练不受影响者身上可能适当；在力量持续提高、飞跑停滞且赛前时间有限者身上，维持力量并重新分配恢复资源可能更合适。这不要求找到普遍的“强到多少就够”，而要求检验当前增量的专项价值。

## Part IV — Training Stimulus & Dose Model

### 1. 刺激的身份来自实施方式

以下矩阵是机制证据与训练设计推理的综合。成本等级不是测得的通用分值；个体剂量、熟悉度、速度和组织状态会改变排序。“暂退”是退出当前角色或方法，不等于永远放弃该能力。

| 方法 | 主要问题与可能机制 | 更适用的条件 | 剂量如何改变性质 |
|---|---|---|---|
| Acceleration training | 提高启动后速度建立、水平冲量与姿态转换 | 分段证据指向早段限制、能耐受起跑姿态 | 距离延长会增加后段速度；间歇缩短会向重复冲刺转变 |
| MaxV training | 暴露于接近当前最高速度的支撑与协调任务 | 助跑、场地和组织耐受允许达到目标速度 | 高速区长度与实际达速次数比总米数更能描述专项暴露 |
| Speed endurance | 在高速进入后维持输出与协调 | 有可用速度水平，后程问题可重复且不是起跑策略造成 | 单次持续时间、相对速度和休息决定是高速保持还是高代谢压力 |
| Resisted sprint | 改变加速中的阻力与用力条件 | 早段问题明确，能校准负载且保留无阻跑检验 | 越重不只是“更多同样刺激”；速度和姿态可能大幅变化 |
| Uphill sprint | 用坡度改变推进任务 | 坡面稳定、坡度合适、可把作用转回平地 | 陡坡降低速度、改变步态与踝需求；坡跑不能替代高速直立跑 |
| Tempo／extensive tempo | 一般体能、低速节奏与可接受活动量 | 确有一般体能需求且不干扰下一次关键训练 | 提速、缩短休息或增加总距离可使其不再低负荷 |
| Strength training | 提高特定动作和角度下的力储备 | 力量限制合理、技术熟练、专项转移可检查 | 相对重量、接近力竭程度、离心量、组数共同决定疲劳 |
| Power training | 较高速度下输出力与功率 | 需要发展快速输出，具备稳定动作 | 负载与速度相互制约；做得很累不等于高功率 |
| Olympic lift derivatives | 快速伸展和负载加速 | 已有技术基础、指导与器械、学习成本可接受 | 拉举、接杠、跳耸肩有不同速度与落地成本，不能统称同剂量 |
| Plyometrics | 训练特定伸缩循环及落地—反弹协调 | 组织和落地技能允许所选任务 | 单／双脚、落差、水平速度、接触数与表面共同决定强度 |
| SSC training | 功能分类，涵盖跑、跳等伸缩活动 | 要解决具体接触和反弹问题 | 不是可在跳跃之外再加一份的独立负荷类别 |
| Isometrics | 特定角度力、快速意图或持续张力 | 需要控制活动范围或补充特定力学任务 | 角度、肌长、强度、时长、发力意图改变适应与成本 |
| General conditioning | 提高承担训练与日常负荷的基础 | 一般工作容量影响训练完成与恢复 | 模式、时长、强度可使其从支持转为竞争目标 |
| Mobility | 处理实际限制任务的活动范围 | 受限范围影响动作执行，而非只是不够“柔软” | 长时间静态拉伸与短动态活动的即时作用不同 |
| Technical drills | 简化任务，提供提示和协调练习 | 能明确观察其是否迁移至跑动 | 更多复杂度或次数可能增加认知与组织负荷，而不增加转移 |

力量、跳跃和等长训练可改变支持能力的证据较充分，但对受训练100米运动员的最优组合远不明确。等长训练的肌长和发力意图会影响适应；举重训练的比较综述没有证明它比其他训练更有效地改善短跑。这些结果支持有条件选择工具，不支持动作排行榜。[^11][^14][^15]跳跃训练提高RSI的汇总证据具有一定支持，但许多参与者未成年，终点也不是100米；不能把代理指标的改善幅度作为成年短跑的预期收益。[^46]

| 方法 | 协同与可能干扰／恢复成本 | 边际收益下降、维持与暂退依据 |
|---|---|---|
| 加速 | 可与力储备及技术练习互补；启动次数、局部肌力与腘绳肌负荷需合计 | 重复增加但目标分段不再保持，先结束加速内容；能力已非主要限制时降为维持 |
| MaxV | 与技术和组织耐受密切相关；可与高强度跳跃、后链力量争用资源 | 达不到预设高速或局部不适时不以慢跑次数补足；比赛期可保留少量优质暴露 |
| 速度耐力 | 将速度能力用于后程；长跑段同时产生机械与代谢成本 | 已满足专项保持要求而妨碍速度训练时维持；技术崩溃超出目标疲劳范围则终止 |
| 阻力跑 | 可支持早段力作用；与普通加速重复计量 | 无阻跑不转移、姿态失去任务价值、负载引发过长恢复时减量或换负载 |
| 坡跑 | 可替代部分阻力条件；踝和小腿负荷可能集中 | 平地转移不见或坡面／局部条件不合适时退出，不把坡度持续增加当进步 |
| Tempo | 可提供低速练习和一般容量；总量多会累积时间与下肢负荷 | 若下一关键课变差，缩短或换低冲击活动；无明确功能时无需为体系完整而保留 |
| 重力量 | 为快速输出提供力储备；离心、新动作和接近力竭可增加成本 | 力量进步却专项无增益且时间有限时维持；症状或明显干扰时改动作／剂量 |
| 功率训练 | 与力量和跑动互补，也可能重复覆盖已有刺激 | 输出明显衰减时停止功率组；已有足够快速输出刺激时保留更低成本工具 |
| 举重衍生 | 熟练者可高效刺激；不熟练者学习与接杠成本较高 | 无独特收益、动作不稳定或赛前学习时间不足时替换，不必强行加入 |
| 跳跃／SSC | 与跑动共享高速伸缩及组织负荷，但任务不完全相同 | 同样接触数下强度升高也算进阶；落地／反弹改变、跟腱反应持续时回退 |
| 等长 | 可精准控制姿势；高强度或长时仍可产生显著疲劳 | 角度力量提高不等于跑动转移；可作维持工具，但不能免除专项暴露验证 |
| 一般体能 | 可支持容量与生活状态；大有氧量或相邻高负荷可能损害快速输出 | 基础容量足够后维持；目标比赛接近时评估机会成本 |
| 活动度 | 可进入热身与技能准备；强拉伸也有恢复成本 | 范围足够后维持；额外范围不改善任务或引发不适时停止追求 |
| 技术drills | 可与短距离尝试构成反馈循环；大量跳步不再是无成本热身 | 连续不能迁移时换提示或任务约束；用“跑得更有效”而非“做得像示范”验收 |

上表的退出规则多为D/F级实践与设计推论，尚无所有方法通用的剂量—收益拐点。肌腱研究、短跑恢复实验和伸展综述分别支持成本依赖加载方式的原则，不能把各研究的具体阈值拼接成统一处方。[^7][^8][^16][^17]

### 2. 阻力短跑的证据分歧

2024年的团队运动专项综述未发现阻力跑在早加速、晚加速或最高速度方面显著优于无阻跑；2025年更广的负载综述报告总体小优势，且不同负载亚组的结果不一致。纳入人群、研究数量、比较模型及距离范围不同，是解释分歧的候选因素，不能仅凭年份决定谁正确。[^18][^19]

因此，合理结论是“阻力跑是加速发展的候选方法”，而不是“所有100米运动员都应拉最重雪橇”。同一体重百分比在不同摩擦、表面和器械下不代表相同阻力；实际速度下降可增加处方可比性，但也须固定无阻参照与测试协议。力量—速度画像可提出假设，最终仍须用无阻分段和恢复反应检查转移。

### 3. 多维剂量模型

仅有Volume与Intensity不够，尤其当Intensity没有定义时。建议记录剂量向量：

**D = {模式；动作／任务；实际速度；强度参照；单次距离或时长；重复与组数；有效高速距离；间歇；密度；频率；高强度暴露次数；外部负重；接触数及类型；表面／坡度；复杂度与熟悉度}。**

外部剂量与内部反应分开。session RPE不是跑动机械负荷；高强度暴露次数也不能取代每次暴露的大小。一次训练里的热身加速、测试、比赛和辅助跳跃可能共享同一负荷来源，应计入实际总量。监测文献支持同时观察外部任务和内部反应，而非用一个任意单位概括所有压力。[^12]

| 维度 | 操作化要求 | 常见误读 |
|---|---|---|
| Volume／distance | 总米数与目标速度范围内米数分开 | 相同600米视为相同负荷 |
| Intensity／velocity | 区分主观努力、实际m/s、相对当前速度、%1RM | “95%”没有分母，或把努力程度当实际速度 |
| Frequency | 实际有效刺激的频率，比赛也计入 | 只数训练课，不数高速暴露 |
| Density／rest | 组内、组间休息及活动方式分开 | 总时长短就以为剂量小 |
| Strength load | 相对重量、重复、剩余次数或速度损失、动作范围 | 同样吨位等于同样神经肌肉刺激 |
| Contacts | 分单／双脚、落差、方向、速度、表面 | 100次pogo与100次高落差跳等量 |
| Complexity | 新旧任务、提示量、技术稳定性 | 新动作只是零成本替换 |
| Exposure | 预定与实际达到的高速／大力任务分别记录 | 没达到MaxV也算完成一课MaxV |

如果同一距离、同一起跑与计时协议下参考最佳时间为t，目标是其平均速度的p倍，则目标时间为t/p；这只是运动学换算，不意味着从站立30米的平均速度能推出飞跑区间的95%最高速度。

### 4. 何时“足够”，何时停止

即时表现不能证明生物学上已经获得“足够适应”。可执行的替代是：先定义本课最低有意义暴露、预期范围和上限，再依据实际质量与反应决定是否继续。最低值与上限需要个人历史校准；它们不是必须完成的配额。

以保持高速质量为目标时，连续计时下降、可重复技术恶化、无法达到目标速度和局部症状都可能支持减少或停止。以耐疲劳为目标时，少量表现下降可能属于刺激本身，但必须预先界定可接受区间和组织边界，不能事后把任何崩溃解释为计划目标。

力量训练实验显示不同组内速度损失可带来不同适应和疲劳，支持记录重复质量。2026年女性篮球运动员小样本研究中，10%和20%速度损失组都出现部分改善，但组间交互不显著；不能以“一组显著、一组不显著”宣称10%优于20%。两类研究也都不能给跑道规定同一停止百分比。[^20][^21]

建议的F级单课规则是：异常出现 → 检查计时／风／执行 → 无症状时允许充分恢复后的有限复核 → 异常持续则停止目标内容或降级。存在突发疼痛、失去正常动作能力等组织问题时，不以重复高速测试来验证是否“真的不行”。

### 5. Development、Maintenance与Minimal Dose

Development dose是在特定窗口推动目标能力提升的剂量；maintenance dose是维持既定水平范围的剂量；minimum effective dose必须说明“对什么终点、在多久内有效”；minimum dose for retention则针对保留，不要求继续增长。detraining是减少或停止刺激后的适应损失，residual effects是相关适应仍然保留的现象，均不是固定到期日期。

一般人群可在显著降低训练量后维持部分力量，但Spiering等明确指出运动员的具体最低剂量资料不足。不能将“一周一次、一组”的一般人群结论直接写成受训练短跑选手的长期力量处方。[^22]

| 能力 | 保留证据与局限 | 本报告建议的监控逻辑 |
|---|---|---|
| Sprint | 直接受训练短跑维持剂量证据有限，且加速与MaxV不能互代 | 降量后保留适当专项接触，并分别看分段与飞跑趋势 |
| Strength | 一般力量保留研究较多；竞技水平与其他训练会改变需求 | 保持有意义的相对负荷，先减多余量，以稳定测试复核 |
| Power | 具体任务适应，不等于力量或肌肉量保留 | 保留可控快速输出；用对应任务验证，不靠1RM推断 |
| SSC | 跳跃与短跑存在部分重叠，不足以证明互相完全维持 | 记录任务类型；高冲击退出时考虑较低成本替代和组织状态 |
| Speed endurance | 100米特定的保留间隔缺乏可靠统一估计 | 用受控后程表现、赛历和实际比赛暴露判断，无固定“保留天数” |

2025年一项40名成年男性短跑者研究要求至少3年运动经历与力量基础，报告6周跳跃训练后部分改善在2周停训后仍高于基线。但测量和同期活动控制的报告有限，且“仍高于基线”不等于“完全保留峰值”，不足以得出统一残留时间表。[^23]

Primary、Maintain、Minimal、Temporarily Withdrawn可以作为资源分配标签：前者获得主要发展预算，第二者有明确保留目标，第三者是在约束下试探更低剂量，第四者附重返条件。必须注明“Minimal是否足以保留尚未确认”，不能把标签当成结果保证。所谓all qualities remain online，较合理的含义是关键能力仍被追踪、存在保留或重返策略；它不要求所有能力每周大量训练，也不要求每个动作常驻。

## Part V — Stress / Recovery Organization

### 1. 用任务名称安排，也用需求重叠检查

动作类别便于沟通，恢复成本更适合检查冲突；二者不是二选一。建议每项任务附带四个维度：高速／快速输出需求、局部组织机械负荷、代谢负担、心理与时间成本。这是F级审核工具，不是将不同疲劳机制换算成一个“神经点数”。

短跑、重力量、高强度SSC与功率训练可能共享部分肌群和组织需求，也存在任务差异。不能把所有疲劳统称CNS fatigue，更不能用低心率推断低局部负荷。重等长、强离心或少量高冲击跳跃都可能心率不高，但相关组织的负荷仍大。

Thomas等让10名男性运动员完成较大剂量的重深蹲、跳蹲或短跑，观察到不同恢复过程，部分指标到48—72小时才恢复；作者明确指出疲劳并非主要由中枢功能下降解释。这是“存在跨任务恢复重叠”的B级支持，不是“任何High之后必须休72小时”的证明。[^16]

### 2. High／Low作为候选组织模型

把多个高需求刺激安排在相近时间，可为其间较低负荷留出空间。潜在代价是同一日总量过高，后面的训练质量下降，或局部组织累积超过可耐受范围。因此，聚类只能在日内总剂量可控、优先任务获得足够质量、次日确实较轻时发挥预期作用。对训练时段有限、单次耐受较低的人，适度分散也可能更好。

High／Low的确切频率、同日力量与短跑次序、低日内容，需要个体比较；目前没有足够证据把某一种排列判为竞技100米普遍最优。若本课首要目的是速度，通常把高速跑安排在未显著疲劳时是合理实践推论；已经个体验证的热身激活例外可存在，但急性PAPE不能自动证明长期训练更优。

### 3. Low day的操作定义

Low应是**相对于此人的当前状态，对下一关键课和相关组织产生较小剩余成本的一天**。它可以包含活动，也可以是休息；需要同时限制量与强度。此定义属于D/F级，不能用一个固定心率区间替代。

| 看似“低”的内容 | 隐藏成本 | 验证方式 |
|---|---|---|
| Extensive tempo | 总距离、表面冲击、加减速、小腿负荷 | 看总米数、局部症状与下一关键课，不只看配速 |
| 长时间轻有氧 | 时间、能量消耗、下肢重复负荷 | 检查是否挤占睡眠／进食／恢复以及慢性目标是否偏移 |
| 大量核心或小肌群 | 接近力竭、局部酸痛、躯干疲劳 | 按实际组数与用力程度记录，不能因肌群小就豁免 |
| 技术练习 | 大量弹跳、反复着地、持续专注 | 把跳步接触计入负荷，检查跑动转移 |
| “恢复性”力量 | 新动作与离心可产生延迟成本 | 基于次日组织反应判断，不依据动作名称 |

Tempo促进恢复的部分解释主要来自教练经验，不能把它写成比休息或其他低冲击活动更有效的已证实结论。Francis档案中的公开文章属于其训练群体的经验材料，作者和年代应与Francis本人著作区分。[^24]

### 4. 24h、48h、72h的使用价值

这些时间点适合安排观察，不能规定所有组织何时恢复。训练后立即输出下降、次日酸痛、48小时局部力下降和72小时飞跑变化可能不同步。重阻力短跑的恢复研究也提示，负载改变可能延长部分表现下降，不能仅按“都是短跑”统一间隔。[^25]

恢复间隔应由前次剂量、训练熟悉度、历史反应、组织状态和下一课任务决定。同一个人可以在某种能力尚未完全恢复时完成另一种可耐受任务；反之，主观感觉好也不证明所有组织均已恢复。观察窗口应随异常延长，不应在72小时自动标记绿色。

### 5. 协同与干扰的证据边界

Schumann等的并行有氧—力量荟萃分析显示，最大力量和肌肥大的整体差异不明确，但爆发力适应存在不利影响，尤其需考虑同一训练课的组织。它不证明所有有氧都妨碍短跑，更不证明把间隔拉到某一小时数即可保证没有干扰。[^26]

需要区分三件事：同课急性疲劳损害下一内容；长期适应间的干扰；有限时间和恢复预算造成的机会成本。即使不存在可证实的分子干扰，大量一般体能占掉高质量跑和睡眠时间，也可能使100米计划更差。

## Part VI — Periodization Models Comparison

### 1. 比较层次与原著核验边界

Traditional、Block、Short-to-Long、High／Low、autoregulation解决的是不同层次的问题，可以组合使用。某计划可同时具有全年准备—比赛结构、短到长的专项发展倾向、高低交替和逐课自动调节。将这些词列成单选菜单会制造假分歧。

Matveyev的1965年俄文书目和1981年英文版书目可核验，但本报告未取得可完整审读的原著全文。因此，下列Matveyev内容限定为可靠文献所述的历史概括，不声称逐条重建其原意。不能把其理论压缩成线性加量；也不能拿Issurin对传统模式的批评当作Matveyev自述。[^3][^27][^28]

Bompa部分采用其与Buzzichelli的出版社原书节选及作者公开说明。Block部分采用Issurin本人论文，但论文中对传统体系的优劣判断仍是该模型提出者的立场。Francis公开材料包括档案编辑文章、论坛用户发言与原书线索，不能混为一手原著。Bondarchuk公开可读部分主要来自直接受其指导者对训练过程的报告；未完成原书全文核验，以下均保留转述属性。[^24][^29][^30][^31][^48]

一个可核验的误归因例子是Francis论坛有关“75%—90%没有积极效果”的讨论：公开页面中的相关解释来自Herb、101pro等用户，并非Francis本人署名回答。因此，该讨论不构成作者原意证据，更不构成中间速度区间普遍无效的科学证明。技术学习、回归跑动及不同耐力任务可能具有不同速度需求，必须按目的判断。[^47]

### 2. 时间、适应与专项性矩阵

| 模型 | 核心问题与适应假设 | 时间组织／重点 | 专项性与竞争适应 |
|---|---|---|---|
| Traditional／Classical | 长期准备如何转为比赛状态；不同阶段承担不同任务 | 准备、比赛、过渡及多尺度训练周期 | 一般与专项比例变化；可有并行内容，不等于完全隔绝各能力 |
| Matveyev | 体育状态的获得、保持和阶段性调整；强调周期结构 | 历史概括为周期、阶段与波动负荷 | 一般准备与专项准备的关系；不能简化为先耐力后速度的唯一序列 |
| Bompa | 把年度目标与体能准备、专项表达相联系 | 按赛事安排多个阶段，力量准备也可分阶段 | 依据项目安排力量发展、转化与维持；不是全年只练一种素质 |
| Block／Issurin | 高水平多目标训练的刺激稀释和多次峰值 | 少数目标的集中块，按残留效应排序 | 集中发展少数能力，其他能力的保留与衔接是关键假设 |
| Bondarchuk | 哪些练习转移至专项，个体何时适应练习组合 | 公开实践以稳定练习组合、反应轨迹及更换组合组织 | 重视一般／专项练习作用；不同变式不宜压成一个固定周期 |
| Vertical integration | 如何发展重点而不丢失已有关键能力 | 同期保留多个要素，改变权重 | 接触与维持不等于所有项目同量发展；依赖最低保留剂量可控 |
| Francis High／Low | 如何为高质量输出保留恢复空间 | 高需求与低需求内容组织 | 以刺激需求而非纯动作类别区分；还需总量控制 |
| Short-to-Long | 如何先建立速度，再扩大高速维持能力 | 专项重点由较短距离逐步延伸 | 早期不等于只有起跑，后期不等于取消短速度 |
| Long-to-Short | 如何从较长跑段逐渐接近更快、更专项的任务 | 距离缩短、速度与专项性逐步提高的常见版本 | 对100／200／400米需分别解释；长跑段不自动等于慢有氧 |
| Concurrent training | 同期承担多个能力目标 | 一个阶段并行训练 | 需区分广义并行与研究中常指的有氧＋力量 |
| Complex／Parallel | 如何组合多种刺激或同时发展能力 | 可能指同阶段并行，也可能指力量—跳跃成对安排 | 名词歧义大，必须展开具体顺序；PAPE与长期适应不能互代 |
| Flexible periodization | 固定目标如何应对生活与状态波动 | 调换课型或调整计划顺序 | 保持目标，改变到达路径；易出现偏好课过多 |
| Autoregulated programming | 当下处方如何匹配可用能力 | 根据RPE、速度或表现逐组／逐课修改 | 特异性由原目标决定，自动调节本身不决定专项内容 |
| Criteria-based progression | 何时准备好接受下一阶段任务 | 根据表现、耐受与恢复进入下一阶段 | 以任务要求为准；不能无限等待“完美达标” |

Short-to-Long与Long-to-Short属于实践组织模式；精英综述描述了这些模式，但没有提供足够的竞技100米头对头实验来证明优胜者。[^32]Vertical integration也是资源分配理念，不能仅凭名称断言优于重点集中的阶段。

### 3. 疲劳、比赛、反馈与失效条件矩阵

| 模型 | 疲劳／恢复处理 | 比赛日期与不确定性 | 能否按反馈改变 | 证据与主要失效条件 |
|---|---|---|---|---|
| Traditional／Classical | 负荷波动、阶段调整与过渡 | 日历协调强；具体执行可修订 | 可以，固定不变不是必要定义 | E及局部A；若把计划曲线当适应曲线则失效 |
| Matveyev | 历史概括涉及周期和恢复，不只是持续上量 | 围绕竞技状态和比赛期组织 | 原著细节未全面核验，不断言禁止调整 | E；未经验证地复制历史运动员负荷与赛历 |
| Bompa | 准备、转化、维持及过渡的负荷管理 | 可按多峰比赛年安排 | 出版社描述承认恢复和阶段条件 | E；固定套用每阶段时长和所有人的力量顺序 |
| Block | 集中负荷后的降低与表现表达 | 可服务多次峰值；要求残留效应与适应时机匹配 | 实践可改，但并不自动解决预测误差 | E、非短跑局部A/B；重要能力掉线或集中刺激不耐受 |
| Bondarchuk | 以专项结果轨迹和稳定刺激观测反应 | 需把个体适应节律与比赛对接 | 公开案例强调反应追踪 | D/E；把投掷经验的训练次数直接移到短跑 |
| Vertical integration | 降低非重点项目剂量 | 保留关键接触便于比赛转换 | 可以调整权重 | D/F；全部项目都被标为必练并大量保留 |
| High／Low | 聚类高需求，低日留恢复空间 | 比赛算高需求，赛历可打断节奏 | 可按恢复改频率或剂量 | D及间接B；高日超载、低日不低、误用CNS解释 |
| Short-to-Long | 短速度的质量边界与逐步增加持续时间 | 与短赛季／室内外衔接可兼容 | 可以回退距离或保持已有刺激 | D/E；耐力接入太晚或早期最高速度暴露超过耐受 |
| Long-to-Short | 长跑段剂量与后续速度暴露的匹配 | 需要足够时间完成向比赛速度迁移 | 可提前保留短速度而非机械等待 | D/E；长期缺少高速接触，临赛突增速度 |
| Concurrent | 用顺序、间隔和优先级限制互扰 | 易覆盖多目标，峰值仍需另行设计 | 可以 | A主要为有氧—力量；目标过多导致刺激稀释和总量失控 |
| Complex／Parallel | 按具体配对与休息，不存在统一恢复模型 | 急性激活需个体试验；长期比赛安排另定 | 可以 | 部分A/B，概念异质；将急性提升当长期适应保证 |
| Flexible | 随状态调整课型和位置 | 日期仍为硬约束；保留备选窗口 | 是其核心 | 间接力量证据与F；频繁逃避关键刺激或连续堆积高课 |
| Autoregulated | 以输出或用力反馈限制实际剂量 | 不自动生成峰值；需上层计划约束 | 是其核心 | A/B偏力量；阈值噪声、仪器误差、每日冲最佳 |
| Criteria-based | 达到任务耐受再推进 | 设复核点、最后决策日和备选目标 | 是其核心 | 复赛共识E、局部B，训练迁移F；标准不可靠或过严 |

周期化力量训练的荟萃分析报告对1RM的小优势，但未证明肌肥大有同样差异；它研究的是力量终点，不是全年短跑计划。另一篇综述指出，很多实验没有将周期化与同样有变化的非周期化方案比较，也没有检验适应发生的时机。因此，不能把“变化优于不变”偷换成“某种全年周期模型已获验证”。[^33][^34]

## Part VII — Monitoring & Autoregulation

### 1. 先估计状态，再决定行动

Athlete state不是一个能直接测量的readiness数字，而是对专项能力、当前疲劳、组织耐受、心理与环境的综合估计。相同CMJ下降可能由疲劳、技术变化或测量误差产生；相同飞跑变慢也可能来自逆风。指标矛盾应触发解释，而不是机械平均成绿色。

可靠性是重复测量稳定性；效度是测量是否代表所声称构念；敏感性是能否检测有用变化；实用性是成本与执行可持续性。下表评价属于基于测量文献的定性综合，不能替代各设备、协议和运动员自己的重测结果。

| 指标 | Reliability／noise | Validity／sensitivity | Practicality与解释边界 | 更合适的决策尺度 |
|---|---|---|---|---|
| Sprint performance | 固定设备、起跑和环境后较好；短距离相对误差较大 | 对对应跑动任务直接，细小长期变化易被噪声盖住 | 测试本身有负荷；不可把不同触发程序混用 | 当课质量＋长期趋势 |
| Strength performance／1RM | 熟悉且协议稳定时重测可靠性通常较高 | 对该力量任务有效，非高速跑readiness的充分指标 | 频繁极限测试成本高 | 阶段性能力评估 |
| Bar velocity | 取决于设备、动作、负荷和最大意图 | 对同动作同负荷输出与组内衰减有用 | 不同设备／均速与峰速不可随意混用 | 当组、当课力量处方 |
| Jump performance／CMJ | 固定动作、手臂、下蹲策略与算法后可用 | 对某些疲劳变化敏感；跳高可被策略补偿 | 成本低于全速跑，但非零 | 支持当课复核＋趋势 |
| RSI | 接触算法、箱高、熟悉度敏感 | 反弹任务相关；对整体短跑准备状态效度有限 | 高强度测试也会加载组织；勿与RSI-mod混用 | 任务特定能力与趋势 |
| RPE | 量表教育和稳定提问提高一致性 | 能描述当下主观用力，不是机械负荷计量 | 受动机、环境和理解影响 | 当课／组内，与输出配合 |
| Session RPE | 固定采样时机和时长定义后更可比 | 提供总体验负荷，难识别局部或短瞬间峰值 | 很实用；长轻课可高于短高速课，不表示组织成本同序 | 课后与周趋势 |
| DOMS | 部位、评分动作与时间固定时可追踪 | 表示酸痛体验，不等于损伤或恢复完成 | 无酸痛不代表能高速跑；疼痛与普通酸痛要区分 | 次日组织问询、局部调整 |
| Subjective fatigue | 个体内一致协议更有价值 | 可对压力敏感，但不定位机制 | 低成本，需可信的报告环境 | 每日与趋势 |
| Motivation | 一致提问可追踪但波动来源多 | 提供心理状态线索，不是能力测试 | 高动机也可能掩盖疲劳 | 对话与当日任务调整 |
| Sleep | 自报和设备各有误差；分期数据需谨慎 | 对恢复背景有意义，单夜分数不决定短跑能力 | 时长、质量、规律和旅行一起看 | 趋势＋异常当日复核 |
| Tissue response | 症状定位、动作和时间需一致 | 对特定任务耐受有价值，不能单独诊断组织损伤 | 持续局部异常的行动优先级高 | 即时、次日、返回高速前 |
| Warm-up response | 受流程与教练判断影响，难完全标准化 | 与当天目标任务相关，但敏感性／特异性未充分验证 | 很实用；不能用“热开了”排除伤病 | 当日处方复核 |
| HRV | 固定姿势、呼吸、时间和设备后更可比 | 反映自主调节的一部分，不等于神经肌肉恢复 | 趋势较适合；高或低均不能孤立判好坏 | 长期背景，少作单一当日开关 |

短跑计时的起跑程序和触发方式可制造大于训练进步的差异；1RM可靠性也不代表其适合每天测试。[^36][^37]CMJ荟萃分析发现多次结果的平均值可能比最高一次更敏感；HRV综述则提醒相似变化可见于不同训练状态，需结合耐受信息。[^38][^39]

主观量表综述支持其对训练反应的敏感性，但研究多使用有验证基础的量表，不能照搬标题而认定任意一个“今天感觉几分”都比所有客观测试好。[^40]睡眠共识支持考虑个体需求和训练生活背景，也不能据此设统一睡眠分数触发取消训练。[^41]

### 2. 噪声与有意义变化

先建立协议一致的个体内基线，再估计典型误差和正常波动。群体内相关系数高，不等于能检测此人0.5%的变化；最小有意义变化也不应不加解释地取群体标准差的某个比例。

操作上保留三个判断：变化可能在噪声内；有值得复核的异常；有重复证据支持的改变。对无症状表现指标，可利用重复观察提高信心；对明确局部症状，不必等到统计显著才调整。不要为了降低测量误差安排过多全速测试，使测量本身破坏训练。

### 3. 最小可行监测组合

建议的F级组合是：简短疲劳／睡眠／局部症状报告，标准化热身中的任务反应，关键跑段的质量记录，以及少量对既定问题有用的力量或跳跃指标。高级设备只有在会改变决策且协议可维持时才加入。无条件的数据越多不一定越好：多指标同时波动会制造大量假警报。

不建议用单一readiness指标独立决定整堂课。例外不是“某指标万能”，而是某类信息的行动后果具有不对称性，例如突发局部疼痛已足以取消当前高速任务，即使其他指标正常。

### 4. Exposure → Response → Decision

| 环节 | 记录内容 | 决策价值 |
|---|---|---|
| Exposure | 实际模式、目标速度达到情况、剂量、环境与原计划差异 | 确认刺激实际发生，区分执行失败和刺激无效 |
| Immediate response | 输出、技术、用力、局部症状 | 限制当课无效追加；必要时停止 |
| 24h | 局部反应、日常功能、酸痛、睡眠和疲劳 | 检查延迟成本；修订下一任务 |
| 48h及必要的后续 | 是否回到可接受范围，目标任务是否可执行 | 判断间隔或剂量是否过大；不按时钟自动放行 |
| 多次暴露后的趋势 | 专项与支持能力、成本、可重复性 | 决定维持、推进、减少或改方法 |

该链条合理，但并未被证明是唯一正确采样节奏。若24小时已有下一关键课，就必须提前使用即时信息和历史反应；不能等48小时才作第一次决策。若异常持续，则延长观察并重新解释原因。

| 观察组合 | 首选解释／行动候选 | 避免的结论 |
|---|---|---|
| 专项稳定、组织可耐受、恢复按预期 | 维持；有明确发展目的才小幅推进 | “没酸痛所以刺激不够” |
| 专项下降、疲劳／症状增加 | 减少或修改、核对压力与恢复 | “需要更拼才能突破” |
| 力量提高、专项无变化 | 检查转移时间、测试条件与优先级，考虑维持力量 | “继续加重量总会变快” |
| 主观差、热身正常、无局部异常 | 沟通背景，保留核心并调整上限的候选方案 | 自动取消或完全忽视主观信息 |
| CMJ正常、冲刺局部不适 | 停止引发症状的跑动，作专项组织评估 | “综合分数绿色，可以全速” |
| 数据缺失、条件改变 | 采用已耐受的较保守选项，补齐影响决策的信息 | 用未知值填零或按最好状态执行 |

自动调节的实验支持主要来自力量领域。即使力量自动调节总体有益，也不能证明复杂的自动生成短跑计划会更好；网络荟萃排名尤其不能代替直接比较和确信区间。[^42]

## Part VIII — Progression & Transition Rules

### 1. 日历进阶与标准进阶的结合

Calendar-based progression提供复核节奏和比赛协调；criteria-based progression提供接受下一任务的证据。四周结束不等于适应完成，但赛历也不能无限推迟。可采用“日期触发复核、标准决定操作”的结构：达到标准可推进，未达到则维持、回退或改变阶段目标，而不是无期限等待。

康复中的复赛连续体将参与、恢复运动和恢复表现区分开；这可以迁移到训练阶段，帮助区分“能做动作”“能完成训练”“能在比赛需求下稳定表达”。复赛框架同时考虑组织健康、任务压力和风险容忍。其逻辑可迁移，具体ACL或腘绳肌阈值不能直接变成健康短跑者的周期转换标准。[^13]

### 2. 进阶不是只加量

进阶可以是相同剂量更快、更稳定、更小恢复成本；也可以是更高速度、更长高速保持、更复杂情境或更接近比赛条件。减少无效辅助训练，让关键训练质量提高，同样可能代表计划进步。改变强度、距离、密度和复杂度时，不宜默认它们互相抵消。

| 决策 | 候选进入条件 | 下一步 | 复核／退出条件 |
|---|---|---|---|
| Maintain | 目标刺激达到、成本可控，尚无需扩大 | 保持关键剂量，继续观察 | 稳定后确有发展空间，或收益／成本改变 |
| Progress | 重复达到质量与耐受目标，有时间完成适应 | 优先改变一项主要剂量维度 | 质量持续下降、恢复超出历史范围则撤回 |
| Reduce | 输出或恢复成本持续不利，但目标仍相关 | 减少重复／高速距离／辅助量或增休息 | 重新达到可接受输出与恢复，才试探增加 |
| Modify | 刺激未解决问题、场地改变或局部不耐受 | 换方法、顺序、距离或约束，保留原适应目标 | 用专项转移和成本验收，而非新动作熟练度 |
| Temporarily withdraw | 组织限制、临赛机会成本或多次不利反应 | 退出该刺激，保留可行替代与重返条件 | 达到组织／任务容忍和重新暴露条件 |
| Transition | 本阶段目标达到，或其边际价值已低于下一阶段 | 改变重点并设置保留剂量 | 关键能力下降或下一任务尚不可耐受时修订 |

这些规则为F级候选，不采用统一“连续两次”“改善3%”“每周加10%”作为硬标准。足够的重复次数取决于噪声、任务成本和决策后果；重大症状不要求先累积多次证据。

### 3. 阶段退出需要五类证据

表现：对应阶段问题是否改善或已达到可接受水平；耐受：是否实际接触过下一阶段的关键任务；恢复：是否能在现实赛历要求的间隔内恢复；技术：质量能否在目标速度和适量重复下保持；组织：有无反复出现的局部不良反应。最后还需检查时间：继续当前阶段是否会挤掉比赛前必要的专项表达和恢复窗口。

若阶段未达目标，先诊断问题是否选错、剂量是否实际达到、试验时间是否足够、恢复是否遮蔽表现、指标是否不敏感，再决定延长。不可把“阶段失败”默认处理为加量。

### 4. 返回高速与医学边界

对明确伤病后的回归，高速接触能力必须在相应组织、功能和任务条件下逐步验证。Askling等对精英短跑及跳跃运动员的随机康复研究是相对贴近目标人群的证据，但它比较的是急性腘绳肌伤后的康复方案，不能证明健康训练者应采用相同进阶时长。[^43]

训练设计系统可以识别与既定医学限制的冲突、记录反应并提醒重新评估，但不能根据跳跃分数或“已休息几天”给出独立医学复赛许可。伤后阶段的目标和责任人应明确。

## Part IX — Taper & Competition Preparation

### 1. 建设能力与表达能力

比赛临近时，新增适应的时间价值下降，当前疲劳的代价上升。表现可能在训练减少后改善，因为短期负面效应减少得比能力损失更快；但这只是有条件的解释，不意味着所有减量必然提高成绩。

Fitness–fatigue模型把训练的正负效应分开，有助于解释“体能提高但当前跑得慢”。它们是对训练—表现关系的数学近似，拟合出的fitness或fatigue不是直接测量的生物实体。参数可能随训练历史改变，不能把耐力模型的时间常数直接套到短跑峰值预测。[^44]

Taper是有目的地降低训练压力以争取表现表达；peaking是目标时点的综合状态与结果。轻松周、伤后卸载、普通休息和比赛减量可能在表面上相似，目标与成功判据却不同。

### 2. 证据支持到哪里

Bosquet等对27项研究的荟萃分析给出约两周、训练量减少41%—60%、保持强度和频率的常被引用结果。但研究组合不是受训练100米运动员的专门剂量试验，不能把这些值发布为短跑最优公式。方向性启示比精确数字更可迁移：减少足以累积疲劳的量，同时保留与表现相关的刺激。[^45]

保持强度并不是要求每次跑100%或每次力量接近极限。应明确保持的是相关速度暴露或相对负荷，同时降低重复、组数或总高速距离；也可因个体恢复、旅行与赛程调整频率。不能在高强度跑量减少的同时，把力量、跳跃或测试量补回来，使总压力不降。

### 3. 比赛前变量的调整逻辑

| 变量 | 通常考虑的方向 | 条件与例外 | 观察依据 |
|---|---|---|---|
| Sprint exposure | 保留少量与比赛相关的速度与起跑接触 | 有组织限制时不能为了“保持强度”强迫全速 | 实际达速、局部反应、个体赛前历史 |
| Volume | 减少高成本重复及不再关键的辅助量 | 原计划已很少时大比例减量可能过头 | 总压力变化，而非只算跑量 |
| Strength | 从发展转向可控的力量维持 | 距赛很近时，新动作或高酸痛成本常不划算 | 相对负荷、速度质量、恢复历史 |
| Plyometrics | 减少冗余高冲击与新颖刺激 | 熟悉的小剂量可能保留；不是一律取消 | 跟腱／足部反应、与跑动的重叠 |
| Speed endurance | 减少导致长恢复的剂量，保留必要任务感觉 | 多轮比赛与兼项需求不同于单枪100米 | 后程能力、赛程、剩余恢复时间 |
| Frequency | 可维持接触节奏，也可调整 | 旅行、疲劳、日常安排和个人偏好影响 | 每次剂量与总体负荷一起解释 |
| Rest interval | 优先保证目标输出与恢复 | 耐疲劳已不再是首要目的时勿刻意压缩 | 热身和关键跑的质量 |
| Novelty／complexity | 降低新颖度和学习成本 | 已知小修改可以保留，但应可逆 | 是否带来不确定酸痛或技术扰动 |
| Monitoring／testing | 保留低成本、可行动信息 | 避免为“确认状态”多次全速测试 | 测试是否会改变赛前决策 |

上述具体组织建议主要是D/F级迁移，不是来自一个覆盖所有变量的100米RCT。比赛轮次、热身、检录等待、旅行、时差和连续参赛本身属于表现准备，不能全部交给减量比例处理。

### 4. 防止表现下降后的错误反馈

赛前状态差时，先排查环境与测量，再检查局部症状、近期负荷、睡眠和比赛／旅行压力，之后才讨论能力不足。如果疲劳累积更符合现有信息，合理候选是减少压力并在适当时点复核；若确有长期缺乏刺激，则考虑熟悉的小剂量重新接触，而不是一次补回欠下的训练。

同样要防止相反错误：一有波动就持续减量，最终使必要接触消失。减量也要有目标、观察点和结束条件。个体曾经有效的比赛准备方案是有价值的先验，但不能无视当前训练背景与组织状态改变。

## Part X — Exercise Selection Logic

### 1. 从问题到工具

建议采用：**观察到的问题 → 可检验的限制因素假设 → 所需适应 → 候选刺激 → 剂量与成本 → 动作选择 → 专项转移复核。**

先问“证据是否足以诊断问题”，再问“什么动作”。30米慢可能涉及起跑程序、技术、力量、反应、环境或疲劳；不能自动分配深蹲。一个动作可产生多种适应，同一适应也可能有多种成本不同的工具。

| 条件性问题 | 候选工具及其理由 | 选择前提／成本 | 什么观察会改变选择 |
|---|---|---|---|
| 一般下肢力储备可能不足 | Squat作为可测、可逐步加载工具；也可考虑其他稳定多关节动作 | 熟练、动作范围适当，力量日不会破坏主要跑动 | 力量升而专项不转移且成本高，转维持或换方法 |
| 髋伸相关力能力或后链加载需求 | RDL提供髋铰链和较长肌长条件下的负荷 | 腰背控制、组织耐受；不等同于高速腘绳肌任务 | 反复酸痛干扰高速跑、任务不耐受，改量或换动作 |
| 快速负载输出需发展 | Jump squat、投掷或举重衍生均是候选 | 依据技能、设备与任务；举重不存在必须性 | 学习时间或接杠成本大于独特收益，则改简单工具 |
| 双侧跳跃基础或一般爆发力不足 | Bilateral jump可提供较易控制的任务 | 双脚任务仍需考虑总量和落地 | 只提高跳跃而无专项相关变化，重新评估优先级 |
| 单侧支撑或方向性任务需要 | Unilateral jump／bounds用于单侧与水平任务 | 不对称不自动是病因；局部冲击可能较大 | 质量下降或局部反应不佳，先降难度而非追求对称分数 |
| 快速落地—反弹控制问题 | Drop jump用于可控落差任务 | 箱高依据实际反弹策略与组织能力，不依据“越高越强” | 箱高增加却接触拖长、反弹质量下降，说明任务改变 |
| 踝主导反弹和节奏练习 | Pogo作为候选 | 高频接触也会累积跟腱与足部负荷 | 局部反应或与跑动冗余增加，则减量 |
| 早段推进问题有重复证据 | Resisted sprint，配无阻跑检验 | 负载校准、表面稳定、实际速度与姿态记录 | 改善仅发生在拉雪橇而非无阻跑，重估转移 |
| 具体活动范围限制跑姿 | 定向mobility与相关动作重学 | 要明确是可改变限制，而不是体型差异 | 范围提高却任务无改善，停止无限增加柔韧性 |
| 技术执行不稳定 | 简化drill、外部约束、视频反馈后立即检验跑动 | 每次聚焦少量信息，固定观察协议 | 只有drill变好，跑动不变，换提示或重新定位问题 |

RDL的合理性来自其加载特征与问题匹配，不能宣称它已被证明比其他动作更提高100米。举重衍生的高功率机制也不证明比较优势；跳跃提高RSI的证据不能替代100米转移验证。[^15][^46]

### 2. 边际价值与维持决策

动作的总历史价值与当前边际价值不同。过去有效的深蹲可能仍值得低剂量保留，却不值得继续占据主要恢复预算；新动作可能改善某项测试，却不足以抵消学习、酸痛和挤占跑动的代价。

优先级可用定性顺序而非虚假精度表达：问题证据强度、专项相关性、个体历史反应、预计成本、剩余时间、替代方案质量。没有足够数据时使用“更值得试验”，而不是“预计提高0.12秒”。

## Part XI — Evidence Map

### 1. 主张、证据与外推范围

| 决策相关主张 | 主要来源 | 来源类型 | 对目标人群的支持与限制 |
|---|---|---|---|
| 计划需要区别外部任务、内部反应和结果 | Halson；出版社概念节选 | E／叙述综合 | 支持组织逻辑，非成套Skill效度研究 |
| 100米机械变量耦合，不宜单指标化 | Morin；Weyand；Schache | B/C | 任务与样本不同；机制不等于训练因果 |
| 能量贡献比例受估计方法影响 | Duffield等 | B/C | 实地跑动相关，但不能反推训练百分比 |
| 力量发展可能转移至短跑 | Seitz等 | A | 混合运动与短距离，不是精英100米确定效果 |
| 跳跃可提高RSI | Ramirez-Campillo等 | A | 年龄跨度大、青年样本多；主要终点为RSI |
| RSI与短跑有相关 | Jarvis等 | A，底层多相关研究 | 不能以改RSI推导100米因果改善 |
| 举重不显示稳定短跑比较优势 | Crenshaw等 | A | 8研究、206人，女性很少，终点多短距离 |
| 阻力跑可能对加速有用 | 2024团队运动综述；Xu等2025 | A | 不同综述比较结果不同；载荷、距离与人群异质 |

| 阻力改变恢复成本 | Recovery kinetics研究 | B | 特定负载协议，不能跨摩擦和场地直接复制 |
| 组内速度损失影响力量刺激 | Pareja-Blanco等；Kambara等 | B | 不同人群与阈值；跑道停止规则仍需验证 |
| 低量可保留部分力量 | Spiering等叙述综述 | E，汇总实验 | 明确缺乏运动员特定建议，不能当100米最低处方 |

### 2. 证据质量、生态效度与经验要分开

内部效度较强的实验能回答受控条件下的方法差异，却可能不包含100米运动员完整赛季中的恢复、旅行和多刺激组合。精英案例生态效度较高，却难排除选材、成熟、并行干预、医疗支持、历史药物背景、幸存者及选择性报告的影响。两者不可互相替代。

教练经验最适合提出候选方法、可实施剂量范围与失败情景；实验研究最适合约束具体干预的因果解释；机制研究帮助识别合理路径与潜在成本。未来系统应同时记录三者，不能将“精英在用”升级为Strong Evidence，也不能以“没有RCT”自动删除实践上成熟的选项。

### 3. 重要分歧的处置

| 分歧 | 本报告采用的解释 | 仍未解决 |
|---|---|---|
| 周期化是否更优 | 有计划变化可能有价值，但现有力量研究不足以验证所有周期理论预测 | 哪种全年100米结构在什么赛历下更优 |
| 重阻力是否优于普通加速 | 应按人群、负载、距离和比较设计拆解；组内进步不等于组间优势 | 受训练短跑者的个体负载选择与长期转移 |
| 高低聚类还是分散 | 均是资源组织候选；比较日内质量与跨日成本 | 同剂量、同赛历下的长期100米比较 |
| 维持需要多频繁 | 低于发展剂量具有合理性，但不同能力的精确底线未知 | MaxV、SSC和速度耐力的个体保留曲线 |
| readiness是否可自动决定训练 | 可辅助局部剂量；必须处理噪声与任务差异 | 哪种多指标决策优于简单教练判断 |
| 减量是否应固定比例 | 方向可参考，幅度需依原始负荷与个人反应 | 高水平100米的最优量、频率与保留刺激组合 |

### 4. 检索与资料可追踪性

检索采用问题导向关键词组合，并对关键主题补查反例和新发表资料。主要组合包括：training plan / programming / periodization；100-m sprint determinants / maximum velocity / acceleration；resisted sprint versus unresisted；velocity loss / quality decrement；minimal dose / retention / detraining；neuromuscular fatigue 24 48 72；CMJ / RSI / HRV reliability validity；criteria-based progression / return to sport；taper / peaking。历史理论分别查找Matveyev原书书目、Bompa出版社节选、Issurin论文、Francis档案以及Bondarchuk直接执教报告。

纳入原则是与问题、机制或决策直接相关，能够核查文献信息与支撑内容；优先保留可识别人群、剂量、比较与终点的研究。器械自行车SIT、游泳100米、机器学习机器人短跑等同名检索结果不被当作田径100米直接证据。论坛匿名讨论仅用于发现资料线索，不作为科学结论依据。

全文阅读用于核对关键概念及部分方法限制；摘要阅读用于较窄的结果判断。全文并非所有引用都已获得，尤其Matveyev与Bondarchuk原著不能提供完整原意校勘。这会降低历史比较的细节确定性，不能被“资料很多”掩盖。各文献后的访问说明反映实际使用深度。

## Part XII — Open Questions / Uncertainty

### 1. 对决策影响最大的未知

1. 受训练成年100米运动员在不同速度水平、性别和训练年龄下，MaxV、加速与速度耐力的发展／维持剂量曲线是什么？已有“athlete”样本远不等于有多年短跑与力量背景。
2. 高质量训练的停止规则能否优于固定低量处方？阈值应使用时间、速度、技术还是多信号；如何区分测量误差和真实疲劳？
3. 将高需求刺激聚类后，获得的恢复空间是否抵消日内质量损失？答案很可能依总剂量、局部组织和可用时段改变。
4. 力量、RSI或模型F–V改善何时真正转移到100米？有没有可用于优先级的“足够”标准，还是只能个体内比较边际价值？
5. 速度暴露、技术熟练与组织耐受是否以不同速度下降？体能保留与重新高速暴露安全性不应视为同一结果。
6. 如何在比赛密集、室内外转换、风与器材变化的情况下估计真实进步？小幅变化需要更严格协议，而非更多自信。
7. 自动调节多久更新一次最有价值？反馈太快会追噪声，太慢会错过组织问题；缺乏直接的100米策略比较。
8. 100米减量的精确长度、频率、最后力量／速度耐力刺激与多轮表现如何匹配？耐力减量结果只能提供有限先验。
9. 女性、接近成年但尚在成熟中的运动员，以及非全职受训练运动员是否需要不同规则？目前不能从男性占多数的研究自动推导一致性，也不能凭人口标签编造固定差异。

### 2. 未来验证应优先测什么

先验证决策过程，再验证表现结果。过程指标包括关键资料缺失时是否拒绝伪精确处方、是否把比赛算作暴露、是否能发现重复刺激和单位错误、是否将组织信号置于相关决策中、是否在足够证据前避免频繁换模型。

结果研究应同时观察标准化分段／飞跑、比赛表现、组织症状与可训练性、完成的目标暴露及恢复成本，而非仅1RM或CMJ。可采用前瞻性个案系列、重复阶段比较及可行的随机对照；长期适应存在延迟与残留，简单AB交叉不一定可逆，不能直接当作药物交叉试验。

对完整系统的初步检验可以比较：固定但保守的基准计划、简单教练反馈、复杂多指标反馈。只有复杂方案额外提高决策价值且执行负担可接受，才有理由增加复杂度。应预先定义分析与修改规则，报告无效和不耐受结果，并记录环境变化及其他干预。

### 3. 可被否证的项目假设

| 假设 | 支持它需要看到什么 | 会削弱它的观察 |
|---|---|---|
| 分层反馈比纯固定表更适当 | 更少已知冲突、更好的目标暴露与恢复，专项至少不差 | 反馈频繁却无额外收益，增加执行负担或漏掉重点刺激 |
| 以需求重叠审核优于动作分类 | 更准确识别延迟成本与重复负荷 | 分类复杂但不能预测或解释相关反应 |
| Maintain标签能释放恢复预算 | 降量后能力在预设范围内保留，主要目标改善 | 支持能力持续丢失，或预算并未真正减少 |
| Criteria-based阶段转换更稳健 | 下一阶段耐受和目标达成更好 | 标准噪声过大、无限延迟，错过赛事窗口 |
| 专项转移复核改进动作选择 | 降低无转移、高执行成本练习的占比 | 过早删除需较长适应时间的有效刺激 |

## Part XIII — Candidate Principles for Future Skill

### 1. 标签说明

Strong Evidence指限定主张在直接测量／相应研究体中支持较强，不代表整套100米处方已获验证。Moderate Evidence指存在一定支持但因人群、终点、剂量或方法学而需保留。Practice-Supported指有可识别实践支持，因果比较不足。Project Hypothesis指本报告提出的可检验设计。Unresolved指不宜默认固定答案。

| 候选原则 | 标签 | 适用条件与调整触发 |
|---|---|---|
| 使用同协议的专项表现评价专项改变，先处理测量条件 | Strong Evidence | 比较分段／飞跑须固定起跑、计时和环境记录；条件变化时降低结论确信度[^36] |
| 不把1RM、CMJ、RSI或单个步态变量等同于100米能力 | Strong Evidence | 限于构念区别与相关≠因果；支持指标改善后仍需专项复核[^5][^6][^10] |
| 力量可以作为短跑支持工具，但当前增量须有专项与成本理由 | Moderate Evidence | 已有力量基础者尤其检查边际转移；专项受损或赛前机会成本增大时转维持[^11] |
| 阻力跑可用于早段问题，选择负载应检验无阻跑转移 | Moderate Evidence | 负载、地面和速度可校准；仅阻力成绩改善时重新判断[^18][^19] |
| 跳跃与等长的作用取决于任务参数，不能按名称开方 | Moderate Evidence | 根据目标终点、组织耐受与具体肌长／意图选择；代理改善而专项不变时复核[^14][^46] |
| 记录重复输出和疲劳衰减，避免无目的追加力竭训练 | Moderate Evidence | 主要证据来自力量；跑动阈值必须另行校准，速度耐力允许的下降需预先界定[^20][^21] |
| 多个高需求刺激可考虑聚类以保留恢复空间 | Practice-Supported | 日内总量和后续质量必须可控；高日过载或低日负担增加时改变安排 |
| Low day应按实际剩余成本确认 | Project Hypothesis | 结合局部组织、总量与下一关键课；低心率但后续不利仍应减少 |
| 不按24／48／72小时自动判恢复 | Moderate Evidence | 时间点用于观察；依据前次剂量、个人历史和下一任务调整[^16][^25] |
| 能力发展和能力维持可用不同预算 | Moderate Evidence | 方向有一般证据；竞技短跑精确保留剂量未知，降量后须复核[^22][^23] |
| 用Primary／Maintain／Minimal／Withdrawn表达资源状态 | Project Hypothesis | 每个标签必须有目标、复核点及重返条件，不能保证结果 |
| 主观反馈与任务表现结合，而非孤立依赖readiness分数 | Moderate Evidence | 使用稳定协议与可信报告环境；冲突信号先解释，组织异常不得被均分掩盖[^38][^39][^40] |
| 日历触发复核，标准决定进退，同时保留比赛时间约束 | Project Hypothesis | 受训练健康运动员的计划迁移；伤后标准由适当专业评估约束[^13][^43] |
| 比赛前可减少高成本量并保留相关刺激 | Moderate Evidence | 已有能力且疲劳有释放空间；确切天数和比例依个体，不能照搬耐力平均值[^45] |
| 减量后状态仍差时先复核原因，不自动增加训练 | Practice-Supported | 区分噪声、疲劳、组织问题与缺刺激；长期少刺激时也需重新接触 |
| 动作在问题诊断后选择，优先可执行且成本可接受者 | Project Hypothesis | 多个工具均合理时比较学习成本、组织需求和个人反应，无最佳动作排行 |
| 原理论、后人改编与当下推论分开标注 | Project Hypothesis | 未核验原著时保留未知，不能用名人标签填补证据 |
| 计划评价先检查可行与一致，再作有条件比较 | Project Hypothesis | 数据不足用“不能判定”；权重来自目标而非固定总分 |
| 不预设每周固定High次数、最低飞跑次数或残留天数 | Unresolved | 等待直接、可迁移证据与个体数据；可作受控试探但不得称普遍规律 |
| 不宣称某一周期模型在所有受训练100米运动员中最优 | Unresolved | 比较必须控制目标、剂量、赛历、执行和人群；现有证据不足 |

### 2. 未来知识记录的建议结构

每一条训练建议至少可追踪到：问题与判据、必要输入、候选适应、可选方法、剂量维度、适用人群、证据类型与确信度、预期时间尺度、观察指标及噪声、停止／回退／阶段转换条件、支持它与反对它的来源。未知应保留为未知，不能由模板自动填成精确数字。

每一次修改至少说明：什么新信息改变了哪项判断、改了哪一维剂量或安排、预期改善什么、何时复核、什么情况撤回。这一记录结构比为每位运动员套一个训练流派更有利于迭代，但其实际价值仍需验证。

### 3. 框架验收情景

| 测试情景 | 合格系统应做出的判断 | 不合格输出 |
|---|---|---|
| 飞跑变快，但换了计时起点 | 先判协议不可直接比较 | 自动宣布MaxV提高 |
| 深蹲PB上升，后续高速课反复下降 | 检查转移、残留疲劳和预算，考虑维持力量 | 因力量进步继续加量 |
| 距比赛很近且局部症状增加 | 优先组织评估与负荷修改，重新解释比赛目标 | 依据赛历自动进入全速冲刺 |
| 所有能力被标为Primary | 指出优先级与资源冲突 | 逐项补齐大量训练 |
| 低日含大量tempo、核心和跳步 | 计算实际负荷与重叠需求 | 因标签Low视为恢复 |
| 中周期日历已结束但关键任务不耐受 | 复核阶段、调整目标或回退 | 自动转入更难阶段 |
| 引用青少年足球10米改善 | 标记年龄、训练史、项目与终点间接性 | 宣称成年100米将同幅改善 |

这些是知识与决策质量测试，不是具体训练计划。它们也不证明最终系统能提高比赛成绩；后者需要前瞻性实施与结果检验。
